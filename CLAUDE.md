# Project Rules

## Emoji Policy
- **No standard Unicode emojis** (e.g. no `U+1F600`-range emoji like heart, skull, DNA, fire, brain, shield, etc.)
- Use **decorative typographic symbols** instead: `✦`, `✧`, `◆`, `◇`, `▸`, `▹`, `✓`, `—`, `⸻`, `·`, `•`, `→`, `←`, `↑`, `↓`
- Or use **SVG icons** for visual elements
- This applies to all HTML content, slide text, and UI elements

## Tech Stack
- **Vite** for dev server and CSS processing
- `npm run dev` serves on localhost:5173 and local network (--host)
- Reveal.js 5.x, GSAP 3.x, D3.js 7.x loaded via CDN
- Vanilla HTML/CSS/JS — no framework required

## Design System
- Warm dark palette: base `#120e10`, rose accent `#c97a8a`, bronze `#a6875f`
- Font: Cormorant Garamond (headings), Inter (body)
- Starry background with twinkling animation on all pages
- Victorian-inspired decorative flourishes
